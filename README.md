# SP-OS (S.J Marco Operating System)

**SP-OS** is a custom-built, lightweight operating system designed to explore low-level hardware interaction, memory management, and kernel development. This project is developed and maintained by **S.J Marco**.

## Core Features
* **Custom Bootloader Integration:** Hand-written assembly entry point to transition the CPU from Real Mode to Protected Mode.
* **VGA Text Mode Driver:** Direct memory mapping to 0xB8000 for screen output and console management.
* **GDT/IDT Configuration:** Custom Global Descriptor Table and Interrupt Descriptor Table implementations.
* **Modular Kernel:** C-based kernel logic for system task management.
