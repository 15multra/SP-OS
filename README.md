# SP-OS (S.J Marco Operating System)

**SP-OS** is a custom-built operating system designed for low-level hardware interaction. Developed by **S.J Marco**.

## Core Features
* **Protected Mode Entry:** Hand-written assembly bootloader.
* **VGA Driver:** Direct memory mapping for console output.
* **Kernel:** C-based logic for system management.
